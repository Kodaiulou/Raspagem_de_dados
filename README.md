#Raspagem_de_dados
Raspagem e coleta de dados no Web Scraper

Projeto simples e eficiente para coleta de dados e criação de tabelas Excel utilizando de bibliotecas do próprio python
esse projeto é apenas uma simulação de como funciona a coleta de dados, o site utilizado é o Web Scraper, raspagem de dados
portanto tudo está dentro da LGPD.
Bibliotecas utilizadas:
Requests*
BeautifulSoup4*
Pandas*

 Requests tem como objetivo "acessar" as URL como uma requisição
 BeautifulSoup pegara elementos das paginas do site e com isso teremos os "dados" do site
 Pandas nesse contexto tem como objetivo tranformar os dados coletados em CSV.
